This game is like GeoGuesser, but using scripture! The game uses a map of 230+ locations from the bible and creates rounds using scripture.

I have added it to github pages at velocisniper.github.io/biblemapper Added mobile scaling as well

As someone who barely knows how to code and just supplied the idea, this was written with the help of AI. I would love to improve my skill one day to not use AI, but for now it helped me make this the way it is.

The library of bible translations was sourced from https://github.com/bobuk/holybooks/tree/master. Copyright (c) 2016, Grigory Bakunov Thanks to the contributers who put that together! I do not own any of the Bible Translations used.

The library of biblical locations was drawn from OpenBibleInfo's Bible Geocoding Data. They did all the heavy lifting of determining what location goes where. This game uses a python script to filter through that data for a simpler map of the most important locations.
The full repository can be found here: https://github.com/openbibleinfo/Bible-Geocoding-Data
